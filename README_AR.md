# يومي — مشروع أندرويد

هذه ملفات المصدر لتطبيق أندرويد محلي يعرض واجهة «يومي» العربية داخل WebView.

## ما يعمل في المشروع
- الشركات مستقلة، لكل شركة أهدافها وتقاريرها.
- تحديد هدف يومي وساعات عمل، والتوزيع المتفاوت على الساعات.
- زر «حفظ» مستقل لكل ساعة يسجل القيمة المقررة دون إدخال مبلغ.
- عند إنشاء الجدول تُسجل تنبيهات محلية لكل ساعة، وتُكرر كل خمس دقائق حتى حفظ الساعة.
- عند الحفظ يُلغى التنبيه التالي لتلك الساعة ويُزال إشعارها الظاهر.
- إعادة جدولة التنبيهات المحفوظة بعد إعادة تشغيل الهاتف.

## بناء APK
1. افتح مجلد `YomiAndroidProject` في Android Studio.
2. دع Gradle يزامن الاعتمادات (يتطلب الإنترنت عند الحاجة).
3. اختر Build > Build APK(s).
4. ثبّت ملف APK الناتج على هاتف أندرويد واختبر الأذونات والتنبيهات.

## حدود النسخة
- هذا مشروع مصدر، وليس APK مبنياً أو مختبراً على جهاز فعلي.
- تنبيهات أندرويد الدقيقة تتطلب إذن المنبهات الدقيقة على الأجهزة المدعومة؛ إذا لم يُمنح الإذن قد تتأخر التنبيهات.
- قيود توفير الطاقة لبعض الشركات المصنعة قد تؤخر تكرار التنبيه، فلا يُضمن توقيت خمس دقائق بدقة في جميع الحالات.
- بيانات الواجهة محفوظة محلياً داخل WebView؛ حذف بيانات التطبيق يمحوها.
- خيار «الأسبوع» يعرض آخر سبعة أيام، و«الشهر» يعرض الشهر الحالي.
- بعد منتصف الليل قد تستمر تذكيرات العمليات غير المحفوظة حتى تُحفظ؛ هذا مقصود وفق المتطلب الحالي.
